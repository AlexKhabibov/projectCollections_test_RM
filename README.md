# Roadmap разработки приложения

## 1. Анализ проекта и API

- Изучение макетов приложения.
- Изучение Swagger и доступных API.
- Определение сущностей и взаимосвязей:
  - Questions
  - Collections
  - Skills
  - Specializations
  - Simulator
- Определение структуры запросов и параметров API.
- Создание TypeScript-интерфейсов для API-ответов.

## 2. Базовая архитектура приложения

- Настройка React + TypeScript + Vite.
- Организация структуры проекта.
- Настройка React Router.
- Создание Layout и основных страниц.
- Разделение приложения на:
  - pages
  - components
  - api
  - store
  - types
  - hooks
  - styles

## 3. Работа с API

- Создание базового API-слоя.
- Настройка `fetchBaseQuery`.
- Подключение API через Redux Toolkit Query.
- Разделение API на отдельные модули:
  - questions
  - question details
  - collections
  - specializations
  - skills
  - simulator.
- Использование `createApi` и `injectEndpoints`.
- Настройка cache и `reducerPath`.

## 4. Список вопросов

- Реализация страницы списка вопросов.
- Получение вопросов через RTK Query.
- Реализация пагинации.
- Реализация поиска.
- Реализация фильтрации.
- Подключение Skills и Specializations.
- Синхронизация фильтров и параметров URL.

## 5. Детальная страница вопроса

- Реализация маршрута `/questions/:id`.
- Получение вопроса через RTK Query.
- Использование `useParams`.
- Обработка состояния загрузки и ошибок.
- Отображение:
  - вопроса
  - изображения
  - ответа
  - информации о навыках и специализации.

## 6. Redux Toolkit

- Создание Redux Store.
- Настройка Redux Toolkit.
- Изучение:
  - `createSlice`
  - reducers
  - actions
  - `useSelector`
  - `useDispatch`.
- Подключение RTK Query middleware.
- Разделение UI-состояния и server state.

## 7. RTK Query

- Переход с обычных `fetch`/loader-функций на RTK Query.
- Использование query endpoints.
- Использование lazy queries.
- Использование `skip` / `skipToken`.
- Работа с cache.
- Использование `injectEndpoints`.
- Разделение API на модули.
- Работа с mutation/query lifecycle.
- Изучение `onQueryStarted`.
- Работа с `updateQueryData`.

## 8. Симулятор собеседования

- Создание страницы настройки тренажера.
- Получение специализаций и навыков.
- Фильтрация навыков по специализации.
- Выбор уровня сложности.
- Выбор количества вопросов.
- Выбор режима вопросов.
- Валидация настроек.
- Запуск симулятора через API.

## 9. Сессия симулятора

- Создание страницы сессии.
- Хранение текущего вопроса в Redux.
- Реализация навигации:
  - предыдущий вопрос
  - следующий вопрос.
- Отображение прогресса прохождения.
- Отображение текущего вопроса.
- Отображение изображения вопроса.
- Реализация кнопки «Посмотреть ответ».
- Скрытие ответа по умолчанию.
- Реализация ответов:
  - «Знаю»
  - «Не знаю».
- Завершение симуляции.

## 10. Экран результатов

- Подсчёт общего количества вопросов.
- Подсчёт известных вопросов.
- Расчёт процента изученных вопросов.
- Отображение статистики.
- Расчёт прогресса по навыкам.
- Визуализация прогресс-баров.
- Отображение списка пройденных вопросов.
- Реализация плиточной сетки вопросов.
- Отображение изображения вопроса в плитке.
- Отображение результата:
  - «Знаю»
  - «Не знаю».

## 11. Модальное окно статистики

- Реализация модального окна.
- Открытие по кнопке «Посмотреть статистику».
- Отображение дополнительной статистики симуляции.
- Закрытие модального окна.
- Работа с состоянием открытия/закрытия.

## 12. Стилизация

- Реализация интерфейса по макетам.
- CSS Modules.
- Настройка:
  - цветов
  - отступов
  - размеров
  - border-radius
  - shadows
  - hover/active состояний.
- Адаптивная верстка.
- Стилизация интерактивных элементов.
- Приведение всех экранов к единому визуальному стилю.

## 13. Работа с HTML-ответами

- Отображение HTML-контента ответа API.
- Использование `dangerouslySetInnerHTML`.
- Подключение DOMPurify.
- Санитизация HTML перед отображением.
- Корректное отображение:
  - `<p>`
  - `<code>`
  - `<pre>`
  - списков
  - форматированного текста.

## 14. Сохранение состояния

- Сохранение состояния симулятора в `localStorage`.
- Сохранение:
  - текущего вопроса
  - списка вопросов
  - ответов
  - статуса завершения.
- Восстановление состояния при перезагрузке приложения.
- Создание `loadSimulatorState`.
- Использование `preloadedState` Redux Store.
- Синхронизация Redux State с `localStorage`.

## 15. Обработка состояний приложения

- Loading states.
- Error states.
- Empty states.
- Проверка отсутствия данных.
- Защита маршрутов от некорректного состояния.
- Обработка отсутствующего вопроса.
- Обработка завершённой симуляции.

## 16. Финальный рефакторинг

- Удаление старых `fetch`/loader-функций после миграции на RTK Query.
- Удаление неиспользуемого кода.
- Проверка TypeScript.
- Исправление типов.
- Проверка Redux Store.
- Проверка RTK Query endpoints.
- Проверка компонентов и пропсов.
- Проверка CSS Modules.
- Проверка адаптивности.

## 17. Финальная проверка

- Проверка всех пользовательских сценариев.
- Проверка навигации.
- Проверка API-запросов.
- Проверка cache RTK Query.
- Проверка Redux state.
- Проверка сохранения в `localStorage`.
- Проверка симулятора от настройки до результата.
- Проверка отображения изображений.
- Проверка HTML-ответов.
- Проверка модального окна статистики.
- Проверка интерфейса по макетам.
